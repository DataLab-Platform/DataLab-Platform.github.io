Plugins#

DataLab prend en charge une architecture de plugin robuste, permettant aux utilisateurs d’étendre les fonctionnalités de l’application sans modifier son noyau. Les plugins peuvent introduire de nouveaux outils de traitement, des formats d’importation/exportation de données ou des éléments d’interface graphique personnalisés, le tout intégré de manière transparente dans la plateforme.

Un plugin est du code Python chargé par DataLab : un simple fichier datalab_<name>.py, ou un paquet distribué sous forme de wheel. Les plugins d’application, par exemple pour la caractérisation de caméras ou de signaux impulsionnels, ou pour l’analyse de radiographies X, ajoutent des chaînes de traitement complètes au panneau Applications et à la page d’accueil.

Trouver des plugins dans le catalogue#

Le catalogue de plugins DataLab recense les plugins maintenus par l’équipe DataLab (Officiel) et par leurs auteurs (Communauté). Chaque version est vérifiée automatiquement avant sa publication : code de plugin en pur Python, licence open source et dépendances fournies par DataLab ou, pour DataLab Desktop, livrées sous forme de wheels supplémentaires ou installées par les utilisateurs dans l’environnement Python de DataLab (voir Dépendances supplémentaires et installation hors ligne).

Pour installer un plugin du catalogue, ouvrez Plugins > Configurer les plugins… dans DataLab et sélectionnez l’onglet Catalogue (voir Onglet Catalogue). Un plugin téléchargé depuis la page du catalogue peut aussi être installé depuis l’onglet Depuis un fichier, y compris dans la version autonome de DataLab. Le catalogue indique les plugins qui fonctionnent aussi dans DataLab-Web (voir Plugins et DataLab-Web).
