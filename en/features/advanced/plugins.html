Plugins#

DataLab supports a robust plugin architecture, allowing users to extend the application’s features without modifying its core. Plugins can introduce new processing tools, data import/export formats, or custom GUI elements — all seamlessly integrated into the platform.

A plugin is Python code loaded by DataLab: a single datalab_<name>.py file, or a package distributed as a wheel. Application plugins, for example for the characterization of cameras or of pulsed signals, or for the analysis of X-ray radiographs, add complete workflows to the Applications panel and to the welcome page.

Find plugins in the catalog#

The DataLab plugin catalog lists the plugins maintained by the DataLab team (Official) and by their authors (Community). Each release is checked automatically before it is published: pure Python plugin code, open-source license, and dependencies provided by DataLab or, for DataLab Desktop, supplied as additional wheels or installed by users in DataLab’s Python environment (see Additional dependencies and offline installation).

To install a plugin of the catalog, open Plugins > Configure plugins… in DataLab and select the Catalog tab (see Catalog tab). A plugin downloaded from the catalog page may also be installed from the From file tab, including in the standalone version of DataLab. The catalog indicates which plugins also run in DataLab-Web (see Plugins and DataLab-Web).
